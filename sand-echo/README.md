# 沙之回响 · Echoes of Sand

完整文档已移至**仓库根目录**的 [README](../README.md)（GitHub 首页展示）。

本目录是 Godot 工程本体。直接编辑：

```bash
godot --path .
```

导出 Windows 单文件 exe：

```bash
godot --headless --path . --export-release "Windows Desktop" "build/windows/sand-echo.exe"
```

结构说明、截图、测试与许可信息见仓库根 [README](../README.md) 与 [`docs/`](docs/)。
